# RoboMundo

Juego web para aprender electrónica y Arduino paso a paso (Robótica, 8vo a 10mo de EGB).
Nombre provisional.

- **Aventura**: 11 mundos de 10 niveles (Arduino, protoboard, LED, programación con bloques o código,
  pulsador, buzzer, potenciómetro, LED RGB, servo, sensores y motores).
- **Laboratorio 3D**: componentes que se giran, se exploran por dentro y se "queman" en experimentos.
- **Retos**: proyectos que se arman desde cero, más un taller libre.
- **Ruta guiada**: actividades paso a paso para quienes la necesitan.

Funciona en el navegador, sin instalar nada. El progreso se guarda con un código por estudiante
(sin nombres) en una hoja de Google mediante Apps Script (`servidor/Codigo.gs`).
